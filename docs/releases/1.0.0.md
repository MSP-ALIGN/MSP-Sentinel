# MSP Sentinel 1.0.0

The first stable release: self-hosted external exposure monitoring that any MSP can install, brand and run.

## Highlights

- **Only what you're allowed to scan:** an "authorised to scan" register with approvals, validity dates and exact
  scope, checked at the moment of every scan, plus a global kill switch.
- **Find what's exposed:** passive discovery of forgotten hostnames, gentle port scans in each client's window,
  certificate and TLS checks, and detection of exposed admin pages and portals.
- **Know what's vulnerable:** software versions matched against NVD, CISA's known-exploited list and EPSS, with an
  honest "confirmed" or "possible".
- **One list per client:** Fail and Warning findings that resolve by themselves, reopen when they come back, and can
  be triaged (accepted risk, false positive) with a note and full history.
- **Hear about it:** immediate alerts for new Fail findings, a summary after each scan, in-app, by email and to Teams,
  Slack or any JSON webhook.
- **Show it:** branded, frozen Executive summary and Technical findings reports, monthly schedule, CSV export.
- **Connect it:** a REST API with scoped, expiring tokens, opt-in triage and scanning, and signed outbound events.
- **Run it:** installer for Ubuntu 24.04 and Debian 12, health checks, encrypted backups, update check, data
  retention, and a full set of guides.

## Install

See [docs/install.md](../install.md). Verify the archive against `SHA256SUMS` and its signature before installing.

## Upgrading

1.0.0 is the first published release: the 0.x versions were development milestones, so there is nothing to upgrade
from. Start with a fresh install. Later 1.x releases upgrade with `sudo ./install/install.sh --upgrade` (see
[docs/upgrade.md](../upgrade.md)).

## Known limitations

- PDFs are made with the browser's "Save as PDF"; server-side PDF is planned for 1.x.
- Monthly reports use calendar months in UTC.
- External checks only: internal scanning arrives with the Sentinel Agent in 2.x. Sentinel is not a PCI ASV scan.
