# User guide

The user guide is now split into short guides, one per task. New to Sentinel? Begin with [Start here](README.md).

| Guide | What it covers |
|---|---|
| [Your first client](guides/first-client.md) | A client's pages, the authorisation, discovery, the first scan |
| [Findings](guides/findings.md) | Grades (Fail, Warning, Info), triage, owners and due dates, verify fix, website and email checks |
| [Search](guides/search.md) | The top-bar search and the filters |
| [Reports](guides/reports.md) | Executive and technical reports, monthly reports, PDF and CSV |
| [Pen-test engagements](guides/engagements.md) | Create, approve, run, stop, report and retest |
| [On-premises agents](guides/agents.md) | Internal scans, enrolment, updates, Active Directory checks |
| [Integrations](guides/integrations.md) | ITFlow (clients and tickets), MSP Align (compliance), NinjaOne, breach monitoring, API |
| [Alerts](guides/alerts.md) | Email, Teams/Slack, notifications, daily fix reminders |
| [Users and security](guides/users-and-security.md) | Roles, two-factor sign-in, users, API tokens, audit log |
| [Running the server](guides/admin-system.md) | System page, updates, backups, retention, demo data, pausing |

**What Sentinel is not:** it checks your clients' networks gently and honestly, from the outside and, where an agent
is installed, from the inside. It doesn't exploit anything, and it is not a penetration test or a PCI ASV scan. See
[Responsible use](responsible-use.md).
